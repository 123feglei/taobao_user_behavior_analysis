## 4. 数据质量问题清单

### 4.1 无表头
字段顺序需手工指定：`user_id, item_id, category_id, behavior_type, timestamp`。若直接用 `pd.read_csv` 不加 `header=None`，第一行数据会被误认为列名。

### 4.2 时间戳异常
- 实测最小值 **1902-05-08 06:32:46**，最大值 **2037-04-09 13:22:35**，远超数据有效期。
- 越界记录 **55,576 行**（占 0.06%），分散在 **338 个**不同日期上。
- 越界记录中，单个日期最多贡献 46,441 行（存在阶段性批量异常）。
- **处理方式**：按 `2017-11-25 00:00:00 ~ 2017-12-03 23:59:59` 过滤。清洗后样例数据的时间范围收敛为 2017-11-25 00:00:00 ~ 2017-12-03 23:59:56。

### 4.3 缺失值（无显著问题）
- 三个 ID 字段与 `timestamp` 能以 `int32/int64` 成功解析，说明**无空值**；
- `behavior_type` 四类取值计数之和 = 总行数（2,015,839 + 5,530,446 + 2,888,258 + 89,716,264 = 100,150,807），说明**无空值、无非法取值**。

### 4.4 重复值（抽样无重复，全量未校验）
- 抽样数据按 `user_id + item_id + timestamp + behavior_type` 校验：**0 条重复**；
- 全量去重校验成本高（需对 1 亿行做哈希），本次未执行，报告中标注为待办。

### 4.5 字段缺失导致的限制（**不可修复**）

| 缺失内容 | 影响 |
|---|---|
| 无金额 / 价格字段 | 无法计算 GMV、客单价；RFM 中的 M 缺失，只能做 RF 分层 |
| 无 session / 会话标识 | 无法切分会话，漏斗只能采用用户级口径 |
| 无用户画像（性别 / 年龄 / 地域） | 归因维度只能限定为类目、时段、行为频次 |
| 仅 9 天数据 | 留存最多算到 7 日；R（Recency）维度区分度不足 |

## 5. 抽样方案

| 项 | 说明 |
|---|---|
| 抽样粒度 | **按 `user_id` 抽样**，而非按行随机抽样 |
| 为什么 | 按行抽样会把同一用户的行为切碎，导致留存、路径、漏斗分析全部失真（PRD 3.3 强调的面试考点） |
| 抽样方法 | 统计每个 `user_id` 的记录数 → 随机打乱 `user_id`（种子 42，可复现）→ 按顺序累加记录数至目标行数 |
| 目标行数 | 100,000 条 |
| 实际结果 | 998 个 `user_id`，100,013 行（整用户保留，实际行数会略超目标） |
| 产出 | `data/user_behavior_sample.csv` |
