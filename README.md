# 淘宝用户行为分析与增长策略

> 基于阿里天池「淘宝用户行为数据集」（约 1 亿条行为记录）的完整数据分析项目：从数据抽取、清洗、入库，到转化漏斗、留存同期群、用户分层、路径归因与增长策略。

**技术栈**：Python（pandas / numpy / SQLAlchemy）· SQL（MySQL 8 / SQLite）· Plotly

---

## 1. 项目背景

某电商平台在 2017-11-25 至 2017-12-03 期间产生约 1 亿条用户行为记录。平台拥有可观流量，但从「浏览」到「下单购买」的转化效率偏低，运营团队不清楚**用户在哪一环节流失、流失的是哪类用户、应优先改善什么**。

本项目要回答的核心问题：

> 在 2017-11-25 ~ 2017-12-03 期间，用户从「浏览」到「购买」的漏斗中，哪一环节流失最严重？流失集中在哪类用户、哪个类目、哪个时段？应采取什么策略、如何验证效果？

---

## 2. 核心结论

| # | 结论 | 数据支撑 |
|---|---|---|
| 1 | **瓶颈环节是「加购/收藏 → 购买」**，流失率 19.23%，高于「浏览 → 加购/收藏」的 14.27% | 浏览 995 → 意向 853 → 购买 689 |
| 2 | **口径差异被量化**：用户级转化率 69.25%，严格有序转化率仅 29.25%，相差约 40pp | `sql/02_funnel.sql` vs `sql/05_path_analysis.sql` |
| 3 | **流失集中在少数类目**：类目 4756105 流失贡献 13.62%，用户级转化率仅 11.88% | `sql/06_drilldown_attribution.sql` |
| 4 | **低频用户是最大的转化洼地**：低频（<30 次）购买率 54.60%，高频（≥100 次）76.24%，相差 21.6pp | 同上 |
| 5 | **时段差异显著**：凌晨 0-5 点购买率仅 14%~18%，晚间 18-23 点为高转化时段 | 同上 |
| 6 | **大促前流量爆发**：日 UV 从 11-25 的 703 升至 12-02 的 973、12-03 的 975（样本共 998 人） | `sql/01_overview.sql` |

**输出策略**：加购未购人群定向召回、低频用户首购激活、时段资源再分配。

## 4. 数据说明与限制

| 项 | 说明 |
|---|---|
| 原始数据 | 100,150,807 行 / 987,994 用户 / 4,162,024 商品 / 9,439 类目 |
| 有效区间 | 2017-11-25 ~ 2017-12-03（占 99.94%）；越界脏数据 55,576 行已剔除 |
| 抽样方式 | 按 `user_id` 抽样（**非按行抽样**），整用户保留全部行为 |
| 样本规模 | 998 个用户 / 99,957 行 |
| 时区 | 时间戳为秒级 Unix 时间戳，已按北京时间（UTC+8）转换 |

**已知限制（报告中均已说明）**：

1. **无金额字段** → 无法计算 GMV / 客单价，RFM 中的 M 缺失，本项目做 **RF 分层**；
2. **无 session 标识** → 漏斗采用用户级口径，并额外给出严格有序口径作为对照；
3. **仅 9 天数据** → 留存最多算到 D7，且 R 维度区分度不足（998 人中仅 23 人 recency ≥ 1）；
4. **样本量有限** → 类目级、时段级结论置信度有限，绝对值不代表平台全量。
